# d3 Audio Meter

**Измеритель уровня звука и монитор LTC-таймкода для disguise Designer.**
Плагин Designer показывает, что сервер disguise отдаёт на выход или принимает на вход,
и выглядит как родной виджет Designer.

[English version](README.md)

![Плагин Audio Meter следит за LTC на входе](docs/ltc.png)

## Возможности

**Выходы** (всё, что Windows выводит на устройство, захват через WASAPI loopback)
- Пиковые метры по каналам: зелёный ниже −12 dBFS, жёлтый выше; черта удержания
  пика краснеет выше −3 dBFS
- Максимальный пик цифрами по каждому каналу и индикатор клипа (сброс одним кликом)
- Спектр на 48 полос, 20 Гц – 20 кГц (можно скрыть)
- Стереокорреляция (+1 моно, 0 широкое стерео, < 0 противофаза)

**Входы — контроль LTC-таймкода** (канал с таймкодом находится сам)
- Крупный таймкод и статус: `LTC OK` / `UNSTABLE` (сбой за последние 10 с) /
  `OVERLOAD` (пик выше −1 dBFS) / `WEAK` (ниже −40 dBFS) / `NO SIGNAL` (со счётчиком
  пропадающих кадров)
- Частота кадров: 23.976 / 24 / 25 / 29.97 DF / 30
- **Потерянные кадры** с последнего сброса — количество и доля, плюс потери за последнюю минуту
- Скачки с размером («jump +250 frames (+10.00 s): expected …, got …»; засчитываются,
  только если их подтвердил следующий кадр, поэтому одиночный битый кадр не считается
  скачком), повторы кадров, пропадания с длительностью («27 frames lost (1.08 s)»)
- Дрожание фронтов как показатель качества сигнала

Интерфейс плагина на английском.

**Окно плагина**
- Открывается маленьким (420×260) и масштабируется; текст переносится или
  уменьшается, но не обрезается
- Несколько окон плагина могут одновременно показывать разные устройства
- Ошибки устройства (например, нет разрешения на микрофон) показываются целиком

## Как это работает

```
устройство Windows ──► agent/audio_meter.py ──WebSocket──► plugin/ (Designer)
  выход: WASAPI loopback     пик · FFT · корреляция            метры, спектр,
  вход:  WASAPI захват       декодер LTC (agent/ltc.py)        панель LTC
```

Designer не отдаёт плагинам аудиобуферы, поэтому захват и анализ делает небольшой
агент на Python и отправляет результат в плагин (~47 обновлений/с). Агент же
раздаёт интерфейс плагина по `http://localhost:8765/`, так что его можно проверить
в обычном браузере.

## Требования

- Windows 10/11 (WASAPI)
- Python 3.11 x64, зарегистрированный в лаунчере `py` (`py -3.11`)
- disguise Designer с поддержкой плагинов (проверено на r32.4)

## Установка

На сервере без интернета:

```bash
install_agent.bat
```

Ставит зависимости из уже скачанных wheel-файлов в `agent/vendor/` (PyPI не
трогает) и запускает агента. Можно запускать повторно — переустановит и
перезапустит.

При наличии интернета подойдёт и обычный способ:

```bash
pip install -r agent/requirements.txt
python agent/audio_meter.py --list      # какие устройства видит агент
```

Запуск агента в фоне (без окна, лог в `agent/agent.log`):

```bash
start_agent.bat
```

или в консоли: `py -3.11 agent/audio_meter.py [--port 8765]`.

Плагин: скопировать папку `plugin` в `<проект>/plugins/audio-meter/` (или в общую
папку плагинов Designer) и открыть **Audio Meter** из меню плагинов. Плагин
подключается к `localhost:8765`; другой адрес задаётся через ⚙ или `?agent=host:port`.

### Важно

- **Для входов нужно разрешение на микрофон.** Параметры Windows → Конфиденциальность
  и защита → Микрофон: разрешить классическим приложениям / Python. Python из
  Microsoft Store иначе молча ждёт согласия и зависает — плагин вместо этого
  показывает сообщение.
- Список устройств агент читает при запуске — после подключения нового
  оборудования его нужно перезапустить.
- Устройства только с ASIO не видны (только WASAPI). Если Designer держит вход в
  монопольном режиме, агент не сможет его открыть и сообщит об этом.
- «Улучшения звука» Windows (тонкомпенсация, эквалайзер) на выходе меняют то, что
  видят метры, — для точных уровней их нужно отключить.

## Тестовые сигналы

Генераторы создают WAV-файлы и карту того, что должен показать плагин:

```bash
python tools/make_test_wav.py                 # уровни, клип, L/R, свип, корреляция
python tools/make_ltc_wav.py                  # LTC 25 fps: скачок, пропадание, клип, слабый и шумный сигнал
python tools/make_ltc_wav.py --fps 29.97 --df
python tools/make_ltc_wav.py --fps 24
```

Проигрывать через виртуальный кабель (например, VB-Cable) или с таймлайна Designer.
Ожидаемые результаты — в `test/*.txt`.

## Структура

| Путь | Что |
|---|---|
| `agent/audio_meter.py` | захват, анализ, WebSocket и раздача интерфейса |
| `agent/ltc.py` | декодер SMPTE LTC с подсчётом потерь, скачков и пропаданий |
| `plugin/` | плагин Designer: `d3plugin.json`, страница, `disguise-ui.css` (стиль Designer) |
| `tools/` | генераторы тестовых сигналов |
| `install_agent.bat` | офлайн-установка зависимостей + запуск |
| `start_agent.bat` | запуск агента в фоне |
